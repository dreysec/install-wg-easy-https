# wg-easy + HTTPS Installer

Интерактивный Bash-установщик **wg-easy + Caddy + Let's Encrypt** для быстрого развёртывания WireGuard VPN с защищённой веб-панелью на Ubuntu/Debian.

## Возможности

- Автоматическая установка Docker и Docker Compose
- Установка wg-easy (`edge` или `15.5.0`)
- HTTPS через Caddy с автоматическим обновлением сертификатов
- Интерактивная настройка домена и SSL
- Правильная настройка Docker-сетей, маршрутизации и NAT
- Поддержка IPv4 и IPv6
- Сохранение конфигурации VPN в Docker volume
- Проверка существующих установок перед запуском

## Требования

- Чистый сервер Ubuntu или Debian (amd64/arm64)
- Root-доступ или sudo
- Домен с DNS A-записью на IP сервера
- Открытые порты: TCP 80, 443 и UDP 51820
- Docker Compose 2.36.0+ (установщик проверяет версию)

## Установка

```bash
git clone https://github.com/dreysec/install-wg-easy-https.git
cd install-wg-easy-https
sudo bash install-wg-easy-https.sh
```

Следуйте инструкциям установщика. Перед внесением изменений скрипт покажет выбранные настройки и запросит подтверждение.

После установки панель будет доступна по адресу:

`https://your-domain.com`

При первом входе завершите настройку администратора и WireGuard.

## Проверка

```bash
docker ps
docker logs wg-easy --tail 50
docker logs caddy --tail 50
docker exec wg-easy ip -4 route
```

## Важно

- `edge` является тестовой версией и может изменяться.
- Скрипт предназначен для новой установки, а не обновления существующей.
- Перед использованием на рабочем сервере рекомендуется проверить установку на тестовом VPS.
- Включите двухфакторную аутентификацию в панели wg-easy.
